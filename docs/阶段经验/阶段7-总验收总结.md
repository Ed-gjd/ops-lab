## 三、阶段7 核心认知（面试可讲）

1. **复制跑通 ≠ 恢复跑通**：只有真杀过一次主库、真 PITR 过一次，才算会——本阶段全真做过
2. **演练暴露的都是真坑**：坐标抓错丢数据、重放起点不对齐重复键、apt 包名撞车（loki 是生物信息软件）、pkill -f 自杀——每个都是经验
3. **SLI/SLO/错误预算**是 SRE 和传统运维的分水岭；**AI 复盘要人审**（AI 会脑补细节）
4. **网络受限时怎么拿软件**：apt 名撞车 → 用 GitHub API 资产端点（api.github.com 通、github.com 不通）
