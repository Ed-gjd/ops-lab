# 阶段7-2：安全加固清单（SSH / 最小权限 / 免密 / 防火墙）

> 依据：运维学习计划阶段7「安全加固」+ SSH 七级（L5-PKI/L7-信任模型）+ 实操经验。
> 目标：一份可直接照做的生产加固清单，含"为什么"。应用目标 = node1/2/3 + 192.168.56.133 + 未来生产机。

---

## 一、SSH 加固（第一优先：攻击面最小化）

| # | 项 | 配置 | 为什么 |
|---|---|---|---|
| 1 | 禁止 root 登录 | `/etc/ssh/sshd_config`: `PermitRootLogin no` | 爆破 root 是最常见的入侵路径 |
| 2 | 禁密码登录 | `PasswordAuthentication no` | 密码可爆破，密钥不可；先确保密钥能登再关 |
| 3 | 白名单用户 | `AllowUsers pc` | 不是所有系统账号都该能 SSH |
| 4 | 改端口（可选） | `Port 2222` | 治标不治本，但能滤掉 99% 扫描噪音；**别依赖它** |
| 5 | 登录限速 | fail2ban | 连续失败自动封 IP |
| 6 | 配置权限 | `chmod 600 /etc/ssh/sshd_config` | 防普通用户读改 |

**顺序铁律**：先配好密钥登录 + 验证能登 → 再关密码登录 → 最后禁 root。**关错锁了自己就进不去了**。

## 二、SSH 密钥安全（免密 ≠ 裸奔）

| # | 项 | 标准 | 为什么 |
|---|---|---|---|
| 1 | 私钥权限 | `chmod 600 ~/.ssh/id_ed25519` | 私钥可读 = 白送 |
| 2 | 目录权限 | `chmod 700 ~/.ssh` | 防别人改你的 authorized_keys |
| 3 | 公钥权限 | `chmod 600 ~/.ssh/authorized_keys` | 同上 |
| 4 | 密钥算法 | 用 ed25519，不用 RSA 2048 | ed25519 更短更安全 |
| 5 | 私钥不共享 | 不传群聊/不放网盘 | 泄露一次=全部失效 |
| 6 | 轮换 | 定期换 key + `rm` 旧公钥 | 人走 key 就要销 |

## 三、最小权限

| # | 项 | 做法 | 为什么 |
|---|---|---|---|
| 1 | 不滥用 NOPASSWD ALL | sudoers 按命令白名单：`pc ALL=(ALL) NOPASSWD: /usr/bin/systemctl status` 这种 | 全放开=账号被盗=root 沦陷 |
| 2 | 日常用普通账号 | root 只在需要时 `sudo -i` | 缩小每一次操作的半径 |
| 3 | 账号审计 | 定期 `cat /etc/passwd` 看有没有陌生账号 | 后门最常见的藏身处 |
| 4 | 服务最小权限 | 服务用自己的低权账号跑，不 all root | DB/nginx 不该是 root |

## 四、防火墙

| # | 项 | 做法 |
|---|---|---|
| 1 | 默认拒绝入站 | `ufw default deny incoming` |
| 2 | 只开必要端口 | `ufw allow 22/tcp`（或改后的端口）+ `443/80` + 业务端口 |
| 3 | 管理网隔离 | 运维口走内网段，不暴露公网 |
| 4 | 出站默认放行 | 学习环境宽松；生产收紧 |

## 五、系统基线

| # | 项 | 做法 |
|---|---|---|
| 1 | 自动安全更新 | `apt install unattended-upgrades` + 启用 |
| 2 | 日志持久化 | journalctl 落盘（`Storage=persistent`），防重启丢证据 |
| 3 | 文件权限抽查 | 查 SUID：`find / -perm -4000` 找异常提权点 |
| 4 | 时间同步 | chrony，防日志时间错乱干扰取证 |
| 5 | 内核/软件源 | 只用官方源，盯 CVE 公告 |

## 落实状态（本机 WSL2）

- WSL2 默认**不跑 sshd**（前面验证过 `sshd.service` 不存在）→ SSH 项以**文档交付 + 待 VM 开机落实**为准。
- 本机已可做：`~/.ssh` 目录权限、私钥权限、密钥算法核查、免密安全自检。
- **后续 VM 开机**（node1/2/3、192.168.56.133）时，逐台按上表落实并回填。
