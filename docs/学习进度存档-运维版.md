## 环境演进记录

- **原 VMware 多机拓扑**（归档参考）：外网段 + 内网段，node1 双网卡做 NAT 网关，node3 内网经 node1 出外网并免密 SSH 到 node1/node2。三台 node 均打过 L1 快照。
- **WSL（当前）**：Ubuntu-24.04 WSL2，systemd 运行中。已有 nginx/mariadb/kubectl/terraform；缺 docker/ansible/jq/shellcheck。**多机阶段计划改用 Docker 容器当节点**。
- **阶段7 曾在 WSL 本地跑过一轮**：mariadb 主从（3306 主 + 3307 从）、nginx 8888 反代、Loki 3100 + Promtail 9081，全真执行。

## 阶段7 成果（2026-08-05 验收，三项全过）

| 验收项 | 结果 | 证据 |
|---|---|---|
| MySQL 主从故障 10 分钟内恢复 | ✅ ~1 秒 | 杀主库 → 从库转正可写 |
| 杀节点演练 + 写总结 | ✅ | 主从复制 → PITR → 故障接管 → 重接，4 个真实坑 |
| 安全加固清单 + 落实 | ✅ | SSH/密钥/最小权限/防火墙/系统基线 |

**阶段7 核心认知（面试可讲）**：
1. **复制跑通 ≠ 恢复跑通**：只有真杀过一次主库、真 PITR 过一次才算会。
2. **演练暴露的都是真坑**：坐标抓错丢数据、重放起点不对齐重复键、apt 包名撞车（loki 是生物信息软件）、pkill -f 自杀。
3. **SLI/SLO/错误预算**是 SRE 和传统运维的分水岭；**AI 复盘要人审**（AI 会脑补细节）。
