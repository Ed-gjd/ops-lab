## 二、课程拆解（10 课，两段式）

### 第一段：底层原理（手搓网络，理解容器网络的真身）

> 你已经用了 Docker/k3s 的网络，但这套"手搓"让你看透它们底层到底干了什么。

**课1：网络命名空间（netns）——容器的"隔离房"**
- 讲：netns 是容器网络隔离的本体，一个 netns = 一套独立的网络栈
- 实验：`ip netns add ns1`，看它的隔离；在 ns1 里 `ip a` 只有 lo
- 验收：能讲清"容器为什么有自己的 IP/路由"，用 `ip netns exec` 进出命名空间

**课2：veth 对——连接两个命名空间的"管道"**
- 讲：veth 永远成对出现，一端进容器、一端进宿主机
- 实验：建 ns1/ns2，用 veth 连起来，两边 ping 通
- 验收：能解释"docker run 时那个 vethXXX 是什么"，手搓一对 veth 互联

**课3：bridge 网桥——多容器互通的中枢**
- 讲：多个 veth 插到同一个 bridge（虚拟交换机），容器就互通了
- 实验：建 br0，把 3 个命名空间的 veth 都插上，全互通
- 验收：能画出"bridge + 多 veth"的拓扑图，讲清它=虚拟交换机

**课4：VXLAN 隧道——跨机器的 overlay 网络（2026 核心）**
- 讲：单机 bridge 不够，多台机器要用 VXLAN 隧道封装；这是 k8s/云网络的地基
- 实验：两台机器建 VXLAN，跨机容器 ping 通（在 node1/node2 上做）
- 验收：能讲清 VXLAN 封装原理（UDP 4789），知道它和 Docker overlay 的关系

**课5：NAT + 端口映射的手搓版**
- 讲：容器怎么出外网（MASQUERADE）、怎么被外网访问（DNAT）
- 实验：给手搓的 netns 加 NAT，让容器能 ping 外网；加 DNAT 让宿主机访问容器
- 验收：能讲清"手搓的 NAT = Docker -p 的底层"，对比你 node1 网关的 MASQUERADE

### 第二段：现代架构（2026 最新成熟实践）

**课6：CNI 选型——Flannel vs Calico vs Cilium（2026 现状）**
- 讲：CNI 是容器网络接口；2026 现状是 Cilium(eBPF) 当默认、Calico 对 BGP、Flannel 最轻
- 实验：查你 k3s 现在用哪个（flannel/VXLAN）；对比三者资源/能力
- 验收：能根据场景选 CNI，讲清 eBPF 和传统 iptables 的本质区别

**课7：eBPF 与 Cilium——内核级网络（2026 前沿，重点）**
- 讲：eBPF 让网络策略在**内核里**执行，不用 iptables 链遍历；Hubble 观测
- 实验：在你 k3s 上装 Cilium（或先只讲概念+查内核是否支持 eBPF），用 `cilium` 命令看端点
- 验收：能讲清"eBPF 网络 vs iptables 网络"的性能差异原理，跑通 `cilium status`

**课8：零信任网络（Zero Trust）——2026 企业标配**
- 讲：NIST SP 800-207，"永不信任、持续验证"；身份即边界，替代"信任内网"
- 实验：用 Cilium NetworkPolicy 做"默认拒绝 + 最小权限"（只允许特定服务互通）
- 验收：能配一条 CiliumNetworkPolicy 实现"只允许 web 访问 db"，讲清零信任三原则

**课9：Service Mesh 选型——什么时候需要（2026 判断框架）**
- 讲：mTLS/流量治理/可观测；2026 结论是"多数团队不需要"，有需求才上
- 实验：用 Cilium 自带能力做 mTLS（比装 Istio 轻）；对比 Cilium mesh vs Istio ambient
- 验收：能用判断框架决定"要不要 mesh"，讲清 sidecar vs 无 sidecar

**课10：综合排错 + 故障演练（收官）**
- 讲：把第一段原理 + 第二段工具串起来，分层定位
- 实验：故意弄坏（断 veth / 关转发 / 防火墙挡 / CNI 挂），让你按层修
- 验收：10 分钟内定位并修复 3 个不同层故障，写一份复盘

## 三、执行协议（写死）

1. **命令全明文**：每个命令先在对话完整写出，再执行，输出全贴，绝不偷懒省略。
2. **用真实环境**：所有例子用 node1/node2/node3/.133 真实机器。
3. **先方案后执行**：破坏性操作（改路由/NAT/CNI/防火墙）先给方案含回滚。
4. **快照兜底**：动网关/CNI 前打快照，坏了能退。
5. **每课验收**：过不了不进入下一课。
6. **结合场景**：每课用真实数据包/真实流量讲，不堆名词。
